Методичні Розробки

Покрокове навчання для новачків у Blender. Створи свою першу 3D модель легко та швидко.

Крок 1

Відкрий Blender

Після запуску Blender ти побачиш стандартний куб у центрі сцени.

Крок 2

Обертання сцени

Затисни середню кнопку миші та рухай мишкою для обертання камери.

Крок 3

Масштабування

Натисни клавішу S та рухай мишкою, щоб змінити розмір куба.

Крок 4

Матеріал

Відкрий вкладку Material та обери колір для своєї моделі.

Крок 5

Рендер

Натисни F12 для створення фінального рендера сцени.

Крок 6

Збереження

Збережи свою сцену через File → Save As та обери папку.
